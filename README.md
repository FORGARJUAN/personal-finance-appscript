# Google Apps Script Automations & Micro-Apps

A collection of production-ready full-stack micro-applications and automations built with **Google Apps Script**, **JavaScript (ES6+)**, **HTML5/Bootstrap 5**, and **Google Sheets**.

---

## 📌 Projects Included

### 1. Personal Accounting & Finance Management System (`Contabilidad personal`)
A full-stack single-page application (SPA) designed for automated expense tracking, financial analytics, and dynamic budgeting.
- **Backend (`Código.gs`):** Handles secure authentication (PIN-based), multi-profile data persistence, CRUD operations, dynamic sheet creation, and automated formula injection (`SUMIFS` for projections).
- **Frontend (`index.html`):** Built with Bootstrap 5, Chart.js for trend/doughnut charts, SweetAlert2 for notifications, and asynchronous communication via `google.script.run`.
- **Key Features:** Real-time expense logging, evidence/receipt upload to Google Drive, budgeting checklist, automated CSV/XLSX export/import, and multi-currency formatting.

### 2. Institutional Election & Voting Platform (`Elecciones`)
A secure digital polling micro-app tailored for institutional democratic voting.
- **Role-based Authentication:** Separate flows and permissions for Admins and Poll Workers (*Jurados*).
- **Dynamic Candidate Presentation:** Grade-specific ballot rendering and one-click vote tallying with prevention of duplicate voting.

---

## 🛠️ Tech Stack
- **Languages:** JavaScript (ES6+), HTML5, CSS3.
- **Platforms & APIs:** Google Apps Script, Google Sheets API, Google Drive API.
- **Libraries & UI:** Bootstrap 5, Chart.js, SweetAlert2.
